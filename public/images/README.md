# Image folders

Use these future destinations when the exact approved assets are exported:

- brand/ — original wordmark, logo, ribbons.
- home/ — astronaut, intro background, planet.
- creation/ — Creation hero and project cover artwork.
- architecture/ — galaxy and SEOULFORM desktop/mobile compositions.
- projects/agora/, projects/stockkernel/, projects/premium/ — verified screenshots.

This starter does not substitute old artwork for Figma assets, fetch temporary
Figma image URLs, or use screenshots of the Figma editor as site images.
No images are wired into the preview, so there are no missing-image requests.

A file at public/images/brand/logo.svg is referenced as /images/brand/logo.svg
at the domain root. The initial hosting assumption is a root-domain deployment,
not a GitHub Pages repository subpath.
